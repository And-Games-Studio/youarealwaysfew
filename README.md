# You Are Always Few website

The public pages of You Are Always Few, served by GitHub Pages at https://and-games-studio.github.io/youarealwaysfew/

- `index.html`: home page.
- `privacy/`: privacy policy (linked from the Play Store listing), with its Italian at `privacy/it/`.
- `terms/`: terms of service.
- `delete/`: how to delete the data the game keeps (the Play Console data safety form links it).

Plain HTML and CSS, no build step. The title font, TallyTitle, was made for the game and is served from here, so the site makes no requests to other servers.
